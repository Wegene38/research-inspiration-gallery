# 科研灵感图库 · 静态镜像

每天从 bioRxiv 与高影响力开放获取期刊（Nature Communications、Science Advances、
Advanced Science 等）自动收集科研插图，并自动提取配色方案，作为论文作图的配色灵感库。

本仓库是图库的**静态只读镜像**：

- 浏览瀑布流图库，每张插图附 6 色配色方案（点击色块复制 HEX / RGB）
- 按期刊筛选、关键词搜索、🏆 排行榜
- 点击插图查看大图与题注，页面底部内嵌 [科研配图配色方案提取器](extractor/)，可交互式重新提取配色
- 「♥ 喜欢」保存在你自己的浏览器里，无需登录

数据由本地采集服务定期重新导出更新。

## 数据与版权

- 插图来自开放获取文章，许可以原文为准（以 CC-BY 为主），每张插图详情页均附原文 DOI 链接与作者信息；
- 本站仅作科研配色灵感展示，请勿将图片用于其他用途；
- 引用请直接通过详情页的原文链接。

## 本地预览

```bash
python3 -m http.server 8080
# 打开 http://localhost:8080
```

直接双击 index.html 也可以，但部分浏览器限制本地 fetch，建议起一个静态服务。

## 数据更新

本镜像由源项目（科研灵感图库）导出生成：源项目在本机定时采集并提取配色，
运行其 `export_static.py` 即可重新生成本仓库全部内容，提交推送后 Pages 自动更新。
